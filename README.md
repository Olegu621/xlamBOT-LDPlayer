# LDPlayer - Special for xlamBOT

Delivery repository for the LDPlayer 9.5.37.0 edition. The official engine installer is verified by SHA-256 and Windows publisher signature before packaging. The edition manifest is signed with the xlamBOT Ed25519 release key.

The edition archive contains only three Windows interface binaries, two avatar assets, the Trebuchet launcher and the extended Android Settings app. No game APK, virtual-machine disk, account, device identifier, password or user data is distributed.

Install and manage instances from the Emulators page of xlamBOT. Source and packaging tool: https://github.com/Olegu621/xlamBOT-source .
`latest-game.json` delivers original Supercell-signed Brawl Stars splits. Game releases contain no account data. Clients validate the signed manifest, file hashes and original publisher certificate; game updates preserve data and wait for stopped bot and closed game.
